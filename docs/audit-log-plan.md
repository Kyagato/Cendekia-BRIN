# Catatan rencana Audit Log

## Batas tampilan awal

- Rencana: tampilkan aktivitas 30 hari terakhir secara bawaan.
- Sediakan pilihan 7 hari, 30 hari, dan rentang tanggal khusus agar admin dapat mencari riwayat lain.
- Batas ini hanya untuk tampilan awal. Catatan lama tetap tersimpan dan dapat dicari; belum ada keputusan untuk penghapusan otomatis atau masa penyimpanan tertentu.
- Status: belum diimplementasikan. Tentukan masa penyimpanan dan kebutuhan arsip bersama pengelola sebelum menerapkan penghapusan apa pun.
